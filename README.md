# K-Content Scout — 한국 관련 영상 검색·추천·자막 도구

한국어 제목과 국내 채널을 포함하여 YouTube 영상을 검색합니다. 조회수나 구독자 대비 배수가 낮아도 수집 후보를 모두 보여주고 S/A/B 추천 등급으로 정렬합니다.

## 실행

동봉 파일들을 같은 폴더에 둡니다. 대시보드 HTML을 브라우저에서 직접 열어 검색할 수 있습니다. 로컬 자막 서버를 이용하려면 이 폴더에서 실행하세요.

```sh
python -m pip install -r requirements.txt
python server.py
```

서버 실행 후 브라우저 주소창에 `http://localhost:5000`을 입력합니다. API 설정에 YouTube Data API v3 키를 입력하고 발굴 버튼을 누르세요. 웹사이트 제한이 있는 키는 현재 접속 주소를 허용해야 합니다. 키를 저장하면 이 브라우저의 localStorage에 보관됩니다.

## 검색

- 키워드는 `|` 또는 쉼표로 구분하며 최대 10개입니다. 중복 키워드는 합칩니다. 한도를 넘으면 안내하고 검색하지 않습니다.
- 기본 검색어: `한국 해외반응 | Korea reaction | Korean food reaction`.
- 여행·음식·사회·K-컬처·다국어 추천 키워드 32개를 제공합니다. 카테고리를 눌러 보고 원하는 칩을 추가하세요. 직접 쓴 검색어도 유지됩니다.
- 키워드마다 관련도순과 조회수순을 모두 조회합니다. 기본 각 3페이지 × 50개로 **키워드당 최대 300개**, 각 5페이지 선택 시 **최대 500개**를 요청합니다. 키워드·정렬 간 중복을 제거하므로 실제 후보 수는 더 적을 수 있습니다.
- 기본 기간은 최근 30일이며 7/14/30/60/90일을 선택할 수 있습니다. 기간·조회 범위·검색어를 변경한 뒤 발굴 버튼을 다시 누르세요.
- 조회 범위에 도달해도 다음 페이지가 있으면 추가 결과가 있음을 표시합니다. 모든 YouTube 영상을 수집하는 것은 아닙니다.
- 조회를 늘릴수록 API 할당량을 더 사용합니다. 10개 키워드 × 두 정렬 × 5페이지이면 검색 요청만 최대 100회입니다. 할당량 부족 시 범위를 줄이거나 프로젝트 할당량을 확인하세요.
- 새 검색은 북마크 탭·결과 내 검색과 이전 결과·자막 선택을 초기화합니다. 빈 결과와 API 실패는 명확히 표시합니다. 샘플은 실제 검색 결과와 구분합니다.

## 등급과 우선순위

등급은 자동 추천용 규칙이며 영상 내용의 진위나 실제 반응을 검증한 평가가 아닙니다. 제목·설명의 검색어 일치도와 일부 다국어 동의어를 사용합니다. 여러 검색어 중 가장 잘 맞는 검색어를 기준으로 계산합니다. 더 정확한 목적에 맞추려면 넓은 검색어를 빼고 구체적인 검색어를 입력하세요.

- 관련성: 최대 75점. 제목 일치율과 설명 일치율 × 0.65 중 큰 값.
- 조회수: 최대 10점. 가점 기준(기본 10만 회)에 도달하면 만점.
- 구독자 대비 배수: 최대 10점. 가점 기준(기본 5배)에 도달하면 만점.
- 최신성: 최대 5점. 업로드 후 90일까지 점차 감소.
- **S**: 관련성 65% 이상이며 총점 60점 이상.
- **A**: S 이외의 관련성 30% 이상 후보.
- **B**: 나머지 후보. 목록에서 제외하지 않습니다.

기본 정렬은 등급 → 점수 → 조회수입니다. 카드와 CSV에 등급·추천순위·점수·관련성을 표시합니다. 조회수/배수 입력은 가점 기준이며 필터가 아닙니다. 구독자 수 비공개·조회 누락은 `확인 불가`로 표시하며 배수를 임의로 만들지 않습니다. 구독자가 0명이면 배수는 계산하지 않습니다. 차트·평균 배수는 배수를 계산할 수 있는 영상만 반영합니다.

## 자막과 오류

검색은 HTML에서 YouTube Data API를 호출하고, Python 서버는 자막 추출을 담당합니다. 검색·영상 상세·채널 상세 API 어느 단계가 실패해도 오류 단계, HTTP 상태, 가능한 경우 원인 코드를 계속 표시합니다. 실패한 통계를 정상 결과로 대신 표시하지 않습니다.

자막은 공개 자막 트랙과 YouTube 접근 허용 여부에 따라 추출이 실패할 수 있습니다. 로컬 서버 연결이 성공률을 보장하지는 않습니다. `메타데이터 스크립트 모드`는 제목·설명이며 실제 자막이 아닙니다.

## 개발 검증

Node.js와 Playwright 및 Chromium이 있는 환경에서:

```sh
node tests/search.spec.cjs
```

테스트는 임시 HTTP 서버와 모의 YouTube API를 사용하며 실제 키를 요구하지 않습니다. 설치된 `/usr/bin/chromium`이 있으면 사용하고, 없으면 Playwright의 Chromium을 사용합니다. 한글 영상, API 실패, 빈 결과, 페이지 조회·중복 제거, S/A/B 정렬, 120개 후보의 상세 배치 조회 등을 검증합니다. 실제 API 키로 외부 YouTube 검색·자막 추출을 검증한 것은 아닙니다.
