# K-Content Scout — 한국 관련 영상 검색·추천·자막 도구

한국어 제목과 국내 채널을 포함하여 YouTube 영상을 검색합니다. 조회수나 구독자 대비 배수가 낮아도 수집 후보를 모두 보여주고 S/A/B 추천 등급으로 정렬합니다.

## 실행

동봉 파일들을 같은 폴더에 둡니다. 대시보드 HTML을 브라우저에서 직접 열어 검색할 수 있습니다. 로컬 자막 서버를 이용하려면 이 폴더에서 실행하세요.

```sh
python -m pip install -r requirements.txt
python server.py
```

서버 실행 후 브라우저 주소창에 `http://localhost:5000`을 입력합니다. API 설정에 YouTube Data API v3 키를 입력하고 발굴 버튼을 누르세요. 웹사이트 제한이 있는 키는 현재 접속 주소를 허용해야 합니다. 키를 저장하면 이 브라우저의 localStorage에 보관됩니다.

## 검색

- 키워드는 `|` 또는 쉼표로 구분하며 최대 10개입니다. 중복 키워드는 합칩니다. 한도를 넘으면 안내하고 검색하지 않습니다.
- 기본 검색어: `Korea "first time"`. 국뽕 영상의 원본 소스를 찾도록 첫 경험·현장 체험 표현을 우선합니다. `국뽕`, `해외반응`만 넓게 검색하면 이미 편집된 해설·댓글 모음도 많이 나올 수 있습니다.
- 원본 소스용 추천 키워드 18개와 주제별 검색어 교체 기능을 제공합니다. 첫 방문·한식·치안·교통·기술·한글 체험·전문가 반응 중 하나를 선택하고 **이 주제로 검색어 교체**를 누른 뒤 발굴하세요. 검색어 교체 자체는 API를 호출하지 않습니다. 추천 칩을 추가하면 기존 검색어와 OR로 합쳐지므로, 정확도를 높이려면 한 번에 한 주제를 권장합니다.
- 여러 키워드를 YouTube의 OR 연산자(`|`)로 **한 검색어에 묶어 관련도순 최대 50개만** 요청합니다. 여러 키워드를 선택해도 `search.list`는 1회 호출합니다. 상세·채널 조회는 별도입니다. 수집 후보 안에서 S/A/B 등급을 계산하며, 전체 YouTube에서 S등급 상위 50개를 보장하는 것은 아닙니다.
- 원본 소스 검색의 기본 기간은 최근 90일이며 7/14/30/60/90/365일을 선택할 수 있습니다. 오늘의 자동 제작은 기존처럼 최근 7일을 사용합니다. 기간·검색어를 변경한 뒤 발굴 버튼을 다시 누르세요.
- 다음 페이지가 있을 때만 **추가 50개 검색** 버튼이 활성화됩니다. 누를 때마다 검색 요청 1회를 보내고 기존 결과에 합쳐 다시 정렬합니다. 영상 중복·조회 불가 때문에 실제 추가 수는 50개보다 적을 수 있습니다. 자동 페이지 조회는 하지 않습니다. 검색어나 기간을 바꾸면 새 검색이 필요하며, 추가 검색 중에는 중복 요청을 막습니다.
- 새 검색과 추가 검색은 각각 검색 한도를 사용합니다. 이미 소진된 일일 한도는 요청 범위를 줄이는 것만으로 복구되지 않습니다.
- 같은 키워드·기간으로 재검색하면 가장 최근 성공 결과를 1시간 동안 재사용합니다. 이 브라우저에 후보 데이터와 조건만 저장하며 캐시에는 API 키를 넣지 않습니다. 추가로 모은 후보와 다음 페이지 정보도 저장하므로 새로고침 후 검색 결과를 불러와 이어서 조회할 수 있고, 브라우저 저장이 차단된 경우 현재 페이지의 메모리 캐시를 사용합니다. 최신 통계가 필요하면 `캐시 대신 새로 조회`를 선택하세요.
- 새 검색은 북마크 탭·결과 내 검색과 자막 선택을 초기화합니다. 실제 빈 결과는 비우지만, API 실패 시 확보된 이전 성공 결과를 원래 검색어 기준으로 복원하고 이전 결과임을 표시합니다. 추가 조회가 한도 초과나 상세 API 오류로 실패하면 기존 결과와 다음 페이지 정보를 보존합니다. 재시도는 사용자가 버튼을 눌렀을 때만 수행합니다. 샘플은 실제 검색 결과와 구분합니다.


원본 소스 검색 예시:

| 주제 | 검색어 |
| --- | --- |
| 첫 한국 방문 | `Korea "first time"` |
| 한식 첫 시식 | `"Korean food" "first time"` |
| 한국 치안 체험 | `Korea "safe" walking` |
| 교통에 대한 호평 | `Seoul subway impressed` |
| 한국 기술 평가 | `Korean technology impressed` |
| 한글 체험 영상 | `외국인 한국 첫 방문` |

## 하루 검색 한도 초과 (HTTP 429 / rateLimitExceeded)

오류에 `Search Queries per day`가 있으면 Google Cloud 프로젝트의 하루 검색 한도를 소진한 것입니다. API 키 오타나 Python 서버 문제가 아닙니다. 같은 프로젝트의 다른 API 키도 같은 한도를 공유합니다.

Google Cloud Console에서 해당 프로젝트를 선택하고 **API 및 서비스 → YouTube Data API v3 → 할당량 및 시스템 한도**에서 `Search Queries per day`의 사용량과 한도를 확인하세요. 한도 갱신을 기다리거나 지원되는 경우 증액을 요청해야 합니다. 이 수정본은 한도를 복구하거나 증액하지 않습니다.

요청 수를 줄이는 기본값·캐시와 오류 안내를 적용했으며 오류를 자동 재시도하지 않습니다. 이미 보유한 영상의 자막·영상 다운로드는 로컬 서버를 사용하므로 YouTube Data API의 검색 한도와는 별개입니다. 단, YouTube 자체 접근 제한으로 실패할 수 있습니다.

## 등급과 우선순위

등급은 자동 추천용 규칙이며 영상 내용의 진위나 실제 반응을 검증한 평가가 아닙니다. 제목·설명의 검색어 일치도와 일부 다국어 동의어를 사용합니다. 여러 검색어 중 가장 잘 맞는 검색어를 기준으로 계산합니다. 더 정확한 목적에 맞추려면 넓은 검색어를 빼고 구체적인 검색어를 입력하세요.

- 관련성: 최대 45점. 제목 일치율과 설명 일치율 × 0.65 중 큰 값.
- 직접 체험·전문가 단서: 제목에 있으면 20점, 설명에만 있으면 10점.
- 놀람·호평·반응 단서: 제목에 있으면 15점, 설명에만 있으면 7.5점.
- 조회수: 최대 7.5점. 가점 기준(기본 10만 회)에 도달하면 만점.
- 구독자 대비 배수: 최대 7.5점. 가점 기준(기본 5배)에 도달하면 만점.
- 최신성: 최대 5점. 업로드 후 90일까지 점차 감소.
- 해설·재편집 표현(반응 모음·해외댓글·총정리 등)은 25점, 부정 평가 표현은 20점 감점합니다. 언어나 채널 국가 자체를 감점하지 않습니다.
- **S**: 한국 관련 단서, 관련성 40% 이상, 직접 체험/전문가 단서와 놀람/호평/반응 단서가 함께 있고 적어도 하나는 제목에서 확인되며, 감점 표현 없이 총점 60점 이상인 원본 후보입니다.
- **A**: S 이외의 한국 관련·관련성 30% 이상 후보 중 감점 표현이 없는 영상입니다.
- **B**: 나머지 후보. 북한만 다루는 영상도 의도한 한국 소스와 구분합니다. 모든 등급의 후보를 계속 표시합니다.

기본 정렬은 등급 → 점수 → 조회수입니다. 카드와 CSV에 등급·추천순위·점수·관련성을 표시하고, 카드에는 체험·반응·재편집·부정 평가 단서를 추가로 표시합니다. 단서만으로 발언자의 국적이나 원본 여부를 확정할 수 없으므로 실제 영상을 확인하세요. 조회수/배수 입력은 가점 기준이며 필터가 아닙니다. 구독자 수 비공개·조회 누락은 `확인 불가`로 표시하며 배수를 임의로 만들지 않습니다. 구독자가 0명이면 배수는 계산하지 않습니다. 차트·평균 배수는 배수를 계산할 수 있는 영상만 반영합니다.

## 자막과 오류

검색은 HTML에서 YouTube Data API를 호출하고, Python 서버는 자막 추출을 담당합니다. 검색·영상 상세·채널 상세 API 어느 단계가 실패해도 오류 단계, HTTP 상태, 가능한 경우 원인 코드를 계속 표시합니다. 실패한 통계를 정상 결과로 대신 표시하지 않습니다.

자막은 공개 자막 트랙과 YouTube 접근 허용 여부에 따라 추출이 실패할 수 있습니다. 로컬 서버 연결이 성공률을 보장하지는 않습니다. `메타데이터 스크립트 모드`는 제목·설명이며 실제 자막이 아닙니다.

## 원본 영상 주소로 자막 추출

검색 결과 아래의 **원본 영상 주소로 자막 추출** 입력란에 주소를 붙여 넣고 **주소로 자막 추출**을 누릅니다. Enter 키도 사용할 수 있습니다. Python 서버(`python server.py`)가 실행 중이어야 합니다.

- 일반 `youtube.com/watch?v=...`, 공유 링크 `youtu.be/...`, Shorts·live·embed 주소 및 11자리 영상 ID를 지원합니다. 영상 주소의 시간·공유 파라미터는 무시하고 영상 ID만 추출합니다.
- API 키와 YouTube Data API 검색 한도를 사용하지 않습니다. 검색 결과에 없는 원본 영상도 바로 작업할 수 있습니다.
- 자막 작업창에서 추출 언어를 선택하세요. 서버가 해당 언어를 찾지 못하면 사용 가능한 다른 언어를 선택할 수 있으며, 반환된 언어를 추출 상태와 SRT 파일명에 반영합니다.
- 추출된 자막은 타임스탬프·전문 복사·SRT 저장·한국어 리뷰 프롬프트에서 사용할 수 있습니다. 제목·채널·통계는 별도로 조회하지 않으며 미조회 상태로 표시합니다.
- 기존 검색 후보는 유지됩니다. 결과 정렬·가점 기준을 바꿔도 직접 연 원본 영상은 유지하며, 다른 후보 카드를 선택하면 해당 영상으로 전환합니다. 새 검색을 실행하면 자막 작업창을 초기화합니다.
- 채널 주소·영상 ID가 없는 재생목록 주소·다른 사이트 주소는 입력 오류로 안내합니다.
- 서버 미실행, 공개 자막 없음, 접근 제한, 응답 시간 초과는 오류로 표시합니다. 주소 직접 입력에서 추출에 실패하면 제목·설명을 자막으로 대신 표시하지 않습니다. 이전 영상의 자막도 남기지 않습니다.

## 영상 다운로드

1. 최신 ZIP의 HTML과 `server.py`를 함께 교체합니다. 실행 중인 서버가 있으면 터미널에서 Ctrl+C로 종료합니다.
2. 앱 폴더에서 `python -m pip install -U -r requirements.txt`를 실행한 후 `python server.py`를 실행합니다.
3. 대시보드에서 실제 영상을 검색하고 카드의 **영상 다운로드 ↓**를 누릅니다. 준비가 끝나면 브라우저가 파일을 저장합니다. 진행 상황과 오류는 검색 상태 아래에 계속 표시됩니다.

MP4를 우선 선택하며 제공 형식에 따라 WebM 등으로 저장될 수 있습니다. FFmpeg가 PATH에 설치되어 있으면 고화질 영상과 음성을 합칩니다. 없으면 이미 영상·음성이 합쳐진 형식을 사용하므로 해상도가 낮거나 지원 형식이 없을 수 있습니다. Python 서버는 한 번에 한 영상을 준비하며, 최대 준비 시간은 3분, 최종 파일은 최대 250MB입니다. 다운로드가 끝나면 서버의 임시 파일을 정리합니다.

샘플 영상과 라이브 방송은 다운로드 대상이 아닙니다. 비공개·로그인 필요·YouTube 접근 제한 등으로 다운로드가 거부될 수 있으며 화면에 오류를 표시합니다. 이 기능에는 YouTube Data API 키가 별도로 필요하지 않지만, 실제 영상을 검색하는 기능에는 API 키가 필요합니다.

## 오늘의 해외 반응 쇼츠 자동 제작

최신 파일 전체를 같은 폴더에 둡니다. 이번 버전에는 **`automation.py`**가 추가되어 HTML만 교체해서는 자동 편집할 수 없습니다.

필수 준비:

```sh
python -m pip install -U -r requirements.txt
ffmpeg -version
ffprobe -version
python server.py
```

FFmpeg와 ffprobe가 없다면 FFmpeg를 설치하고 새 터미널에서 서버를 다시 실행하세요. Windows는 `winget install --id Gyan.FFmpeg -e`, macOS는 `brew install ffmpeg`를 사용할 수 있습니다. FFmpeg에는 `libx264` 인코더와 `subtitles`(libass) 필터가 필요합니다. 한국어·일본어 등 자막에는 해당 언어를 지원하는 글꼴을 설치하세요.

대시보드의 **오늘의 해외 반응 쇼츠 자동 제작 → 쇼츠 자동 제작 시작**을 누르면 다음 단계를 진행합니다.

1. **후보 선정**: 현재 입력한 키워드로 최근 7일 영상을 최대 50개 조회하고 S/A 등급·추천 점수 순으로 최대 3개 후보를 정합니다. 검색 요청은 1회이며 같은 조건은 기존 캐시를 사용합니다. 실시간 트렌드 키워드를 외부에서 수집하는 기능은 아닙니다. 키워드·조회수·배수·최신성으로 오늘 제작할 후보를 추천합니다.
2. **자막·원본 확보**: 후보 순서대로 실제 타임스탬프가 있는 자막과 원본 영상을 확보합니다. 자막이나 다운로드가 실패하면 다음 후보를 시도합니다. 자막 도구 실패 시 yt-dlp의 JSON3 자막으로 재시도하며 타임스탬프를 임의 생성하지 않습니다.
3. **구간 추천**: 자막에서 한국 관련 표현과 감탄·긍정 반응을 찾아, 앞부분 맥락을 포함하는 10~59초의 연속 구간을 최대 3개 선택합니다. 겹치는 구간은 제외합니다. 부정 표현·자막이 희박한 구간은 제외합니다. 의미를 완전히 이해하는 AI 모델이 아니라 명시적인 키워드 규칙입니다. 실제 발언의 맥락·국적·반응은 결과 원문과 함께 검토하세요.
4. **세로 편집**: 720×1280(9:16), 30fps, H.264/AAC MP4로 저장합니다. 원본 전체 화면을 중앙에 배치하고 배경을 흐리게 채웁니다. 원본 음성과 추출된 언어의 자막을 사용합니다. 자동 한국어 번역·더빙·새 내레이션은 포함하지 않습니다.
5. **검증·저장·보고**: 파일을 실제로 렌더링한 뒤 해상도와 60초 미만 길이를 확인합니다. 완료 화면에 원본, 선정 구간, 저장 파일, 후보별 실패 이유를 표시합니다.

**자막 작업창의 영상 사용**을 선택하면 검색 없이 선택한 원본을 바로 제작합니다. 주소로 직접 연 영상도 사용할 수 있고, 이 경로에는 검색 API 키가 필요하지 않습니다. 샘플 영상은 사용할 수 없습니다. 최대 쇼츠 수를 1/2/3개 중 선택할 수 있지만 충분한 구간이 없으면 실제 생성 개수는 줄어듭니다. 모든 후보가 실패하거나 적합한 구간이 없으면 성공으로 처리하지 않고 실패 보고서를 저장합니다.

결과는 **Python 서버가 실행되는 PC의 `outputs/<작업번호>/`**에 남습니다. 원본은 최대 250MB·1시간 이하만 처리하며 임시로 탈락한 후보의 파일은 정리합니다. 완성 결과는 사용자가 삭제할 때까지 유지됩니다.

- `<영상ID>/original.mp4` 등: 원본 파일
- `<영상ID>/transcript.json`, `transcript.srt`: 전체 자막
- `<영상ID>/short-01.mp4`, `short-01.srt` 등: 쇼츠와 해당 구간 자막
- `report.json`, `report.txt`: 선정 사유·원문·원본 시간 구간·길이·해상도·오류 내역
- `shorts-results.zip`: 쇼츠·자막·보고서 묶음. 용량이 큰 원본은 별도 다운로드합니다.

브라우저를 닫아도 서버와 작업 프로세스가 실행 중이면 제작을 계속합니다. 다시 열어 **최근 작업 상태 확인**을 누르면 마지막 작업의 진행·결과를 확인할 수 있습니다. 자동 업로드나 예약 실행은 하지 않으며 버튼을 누를 때 제작을 시작합니다.

## 개발 검증

Node.js와 Playwright 및 Chromium이 있는 환경에서:

```sh
node tests/search.spec.cjs
python -m unittest discover -s tests -p 'test_*.py' -v
```

테스트는 임시 HTTP 서버와 모의 YouTube API를 사용하며 실제 키를 요구하지 않습니다. 설치된 `/usr/bin/chromium`이 있으면 사용하고, 없으면 Playwright의 Chromium을 사용합니다. 한글 영상, API 실패, 빈 결과, 페이지 조회·중복 제거, S/A/B 정렬, 120개 후보의 상세 배치 조회 등을 검증합니다. 실제 API 키로 외부 YouTube 검색·자막 추출을 검증한 것은 아닙니다.

다운로드 검증은 모의 파일의 브라우저 저장, 서버 미실행·구버전·실패 안내, 파일 전송·임시 파일 정리·용량 제한·시간 초과를 포함합니다. 개발 클라우드에서 실제 YouTube 연결은 네트워크 정책의 HTTP 403으로 차단되어 실영상 다운로드는 검증하지 못했습니다.

검색 한도 회귀 검증: 기본 요청 수, 동일 조건 캐시·새로고침 후 캐시, 명시적 새 조회, 캐시 만료, 하루 한도 HTTP 429 안내, 이전 성공 결과 보존, 추가 페이지 결과 보존, 새로고침 후 페이지 이어받기, 조건 변경 시 추가 조회 비활성화, 중복 클릭 방지를 모의 응답으로 검사합니다.

주소 직접 입력 검증은 지원 링크·잘못된 주소, API 키 없이 추출, 기존 결과 보존, 실제 형식의 SRT 파일 저장, 서버 미실행·자막 없음, 언어 변경 시 이전 응답 덮어쓰기 방지를 모의 서버 응답으로 확인합니다. 외부 YouTube 원본 영상의 실자막 추출을 검증한 것은 아닙니다.

자동 제작 검증: API 제출·작업 상태·다운로드 파일 제한·실패 보고, 자막 시각 보존·구간 길이·중복 제거, 시험용 원본을 이용한 실제 FFmpeg 세로 영상·음성·자막 렌더링과 ZIP 저장을 검사했습니다. 개발 클라우드의 YouTube 접속은 프록시 HTTP 403으로 차단되어 실제 인기 영상의 자동 제작 성공은 검증하지 못했습니다.

원본 소스 추천 검증: 주제 교체 시 요청 없이 검색어만 교체, 실제 검색 1회 유지, 한글·영문 직접 체험 후보 우선, 높은 조회수의 재편집/부정 평가/북한 영상 과대평가 방지, 설명에만 있는 표현으로 S등급 부여 방지를 모의 데이터로 검증합니다. 실제 검색 결과의 품질 향상 정도는 사용자 API로 확인해야 합니다.
